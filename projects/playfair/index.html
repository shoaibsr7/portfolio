🔐 Playfair Cipher

  • Java
  • JavaScript

The Playfair cipher encrypts pairs of letters using a 5×5 grid built from a secret key. It was used in the Boer War and World War I. Type a key and a message, then click any pair to see exactly how it was transformed.

The rules

  • Build the square: write the key's letters without repeats, then fill in the rest of the alphabet. I and J share a cell so it fits in 25.
  • Split into pairs: if a pair would have the same letter twice, put an X between them. If one letter is left at the end, pad it with X.
  • Same row: take the letter to the right of each (to the left when decrypting).
  • Same column: take the letter below each (above when decrypting).
  • Rectangle: swap each letter for the corner in its own row on the other side.
  • This started as a Java project at Dalhousie, with methods to build the key matrix, encrypt and decrypt. This page runs the same algorithm in JavaScript so you can watch it work.
