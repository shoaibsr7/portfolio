Pizza Ordering Bot

  • Amazon Lex V2
  • AWS Lambda
  • Python
  • Amazon Cognito
  • S3 + CloudFront

A chatbot that walks you through ordering a pizza: choose a restaurant, size, type, crust and topping in plain conversation. It's behind a sign-up and login page. I built it for a cloud computing course at Dalhousie University in April 2024.

Sign in and try the bot View the source ↗

How it works

  1. Sign inAmazon Cognito handles sign-up, email verification and login.
  2. ChatA chat widget on the page connects you to an Amazon Lex V2 bot.
  3. UnderstandLex works out what you want and collects the order details.
  4. ValidateA Python Lambda function checks each answer and re-asks if it doesn't match the menu.
  5. HostThe static pages are served from a private S3 bucket through CloudFront over HTTPS.

What I learned

  • Designing a Lex conversation with intents, slots and slot types, and handling invalid answers gracefully.
  • Writing a Lambda code hook that validates slots and returns the right dialog action to Lex.
  • Adding authentication with a Cognito user pool and its hosted sign-in page (OAuth 2.0 authorization code flow).
  • Hosting a static site on S3 behind CloudFront, and locking down the IAM permissions for each piece.
