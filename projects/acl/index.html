🛡️ ACL Simulator

  • Java
  • JavaScript
  • Networking
  • Cisco IOS syntax

Routers use access control lists to decide which packets get through. Write some rules, send some packets, and watch each one get permitted or denied. Rules are checked top to bottom, the first match wins, and anything that matches nothing is dropped by the hidden deny any at the end.

View the Java source ↗
Try an example:

Standard (1–99): access-list 10 permit 172.16.0.0 0.0.255.255
Extended (100–199): access-list 101 deny tcp any host 10.0.0.5 eq 23
any, host x.x.x.x, wildcard masks, and eq with a port number or name (http, ssh, dns…) all work. ! starts a comment.

One per line: source [destination] [protocol] [port]. Standard lists only look at the source.

        How it works

        • Wildcard masks are the reverse of subnet masks: a 0 bit means "must match" and a 1 bit means "don't care". So 172.16.0.0 0.0.255.255 matches anything in 172.16.x.x.
        • Standard lists only look at the source address, so they're usually placed close to the destination.
        • Extended lists also check the destination, protocol and port, so they can block one service (like Telnet) and allow everything else.
